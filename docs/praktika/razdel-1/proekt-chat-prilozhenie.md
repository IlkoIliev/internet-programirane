## 3. Протоколът на екипа

Преди да пишете код, договорете се **как** клиентът и сървърът ще различават обикновено съобщение от команда. Препоръка: **ред, който започва с `/`, е команда**; всички останали редове са съобщения.

Опишете протокола в `README.md` с таблица като тази:

| Посока | Ред | Значение |
|---|---|---|
| клиент → сървър | първият ред | името на потребителя |
| клиент → сървър | `текст` | съобщение до всички |
| клиент → сървър | `/exit` | изход |
| клиент → сървър | `/users` | заявка за списъка с потребителите |
| клиент → сървър | `/w Име текст` | лично съобщение |
| сървър → клиент | `Име: текст` | съобщение |
| сървър → клиент | `*** ...` | известие |
| … | … | … |

!!! tip "Защо протоколът е важен"
    Ако един член на екипа реши, че списъкът с потребителите идва като `*** В чата са: Иван, Мария`, а друг очаква `/users Иван,Мария`, клиентът и сървърът „не се разбират“, въпреки че кодът на всеки от тях е верен. Точно затова интернет се основава на **стандартизирани** протоколи като HTTP.

## 4. Подсказки

### 4.1. Команди в сървъра

В `HandleClientAsync`, в цикъла за четене, след проверката за `/exit`, разпознайте командите, **преди** да препратите реда до всички:

```csharp
                    if (line.StartsWith("/w "))
                    {
                        string[] parts = line.Split(' ', 3);   // "/w", "Мария", "текст"
                        if (parts.Length == 3)
                            await SendPrivateAsync(client, parts[1], parts[2]);
                        continue;
                    }

                    if (line == "/users")
                    {
                        await client.SendAsync($"*** В чата са: {GetUserList()}");
                        continue;
                    }
```

### 4.2. Лично съобщение

Намерете получателя по име (в `lock`, защото списъкът се променя едновременно) и изпратете само на него:

```csharp
    // Изпраща лично съобщение до един клиент
    static async Task SendPrivateAsync(ClientConnection from, string toName, string text)
    {
        ClientConnection? to;
        lock (clientsLock)
        {
            to = clients.FirstOrDefault(c => c.Name == toName);
        }

        if (to == null)
        {
            await from.SendAsync($"*** Няма потребител с име {toName}.");
            return;
        }

        await to.SendAsync($"(лично) {from.Name}: {text}");
        await from.SendAsync($"(лично до {toName}) {text}");
    }
```

### 4.3. Списък с имената

```csharp
    // Връща имената на свързаните клиенти, разделени със запетая
    static string GetUserList()
    {
        lock (clientsLock)
        {
            return string.Join(", ", clients.Select(c => c.Name));
        }
    }
```

`FirstOrDefault` и `Select` са методи от LINQ (`System.Linq`), които се добавят автоматично в проектите на .NET 10.

### 4.4. Графичен клиент със списък на потребителите

Ако сървърът изпраща списъка в специален формат, например `/users Иван,Мария,Петър`, графичният клиент трябва да разпознае този ред и да попълни `lstUsers` вместо `lstMessages`. Получените редове пристигат в ламбда израза, който `btnConnect_Click` подава на `session.ReceiveAsync` (упражнение 6, раздел 5). Добавете във формата метод `ShowLine`:

```csharp
    // Разпределя получения ред: списък с потребители или обикновено съобщение
    private void ShowLine(string line)
    {
        if (line.StartsWith("/users "))
        {
            lstUsers.Items.Clear();
            lstUsers.Items.AddRange(line.Substring(7).Split(','));
        }
        else
        {
            AddMessage(line);
        }
    }
```

и в ламбда израза заменете `AddMessage(line);` с `ShowLine(line);`:

```csharp
            await session.ReceiveAsync(line =>
            {
                if (ReferenceEquals(current, session) && !closing)
                    ShowLine(line);
            });
```

Проверката `ReferenceEquals(current, session) && !closing` остава – тя пази списъка от редове на стара връзка и от затворен прозорец. Не забравяйте да изчистите `lstUsers` при изключване (например в `SetConnected(false)`).
