## Интерактивни конструктори

В конструкторите пишете код и веднага виждате резултата, грешките и кои елементи избира всяко правило. Работата в конструктора подготвя самостоятелната работа във Visual Studio Code.

- [**HTML конструктор**](../../interaktivni/razdel-2/html-konstruktor.html){: target="_blank" } – мисии за изграждане на структурата на страница с HTML елементи.
- [**CSS конструктор**](../../interaktivni/razdel-2/css-konstruktor.html){: target="_blank" } – мисии за селектори, свойства, кутиен модел и контраст, плюс свободен режим за проверка на собствената страница.
