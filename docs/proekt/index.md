# Общ проект: Училищни клубове

Примерно приложение за управление на клубове, ученици и записвания.

## Етапи

1. Изисквания и моделиране.
2. HTML/CSS/JavaScript интерфейс.
3. ASP.NET Core MVC приложение.
4. Entity Framework Core и CRUD.
5. Автентикация и роли.
6. REST API, интеграция и тестове.

**Важно:** това е предложен общ проект, а не замяна на самостоятелните задачи от учебното разпределение.
